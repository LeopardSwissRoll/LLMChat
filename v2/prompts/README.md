# prompts/

페르소나 프롬프트 자산 디렉터리. **실제 페르소나 폴더는 저장소에 포함되지 않는다** — 캐릭터 설정용으로 수집한 외부 텍스트가 섞여 있어 공개 배포 대상이 아니다. 이 문서는 `PromptComposer` 가 기대하는 레이아웃을 설명하고, `example/` 은 그 규약을 따르는 최소 예시다.

## 레이아웃

```text
prompts/
├── bot_global.md          # 모든 페르소나 공통 서두 (선택)
├── providers/
│   ├── claude.md          # provider 별 추가 지시 (선택, 비어 있어도 됨)
│   └── codex.md
└── <persona_dir>/
    ├── PROMPT.md          # 필수. @@N 섹션 규약을 따른다
    └── ...                # 참고 자료. @레퍼런스 마커로 경로가 주입되고 --add-dir 로 노출된다
```

`PERSONAS` 환경변수(또는 `default_state.json`)의 `dir` 값이 `<persona_dir>` 이 된다.

## PROMPT.md 섹션 규약

`PromptComposer` 는 `## @@N:` 헤더로 문서를 잘라 **페르소나 강도(LV1~5)** 를 만든다.

| 모드 | 이름 | 포함 섹션 |
|---|---|---|
| 1 | core | `@@1` 만 |
| 2 | soft | `@@1` ~ `@@3` |
| 3 | medium | `@@1` ~ `@@4` |
| 4 | hard | `@@1` ~ `@@5` |
| 5 | masquerade | 문서 전체 |

즉 `@@1` 은 항상 들어가는 정체성 핵심, 번호가 커질수록 말투·관계 보정처럼 "강도가 높은" 지시를 둔다. 슬래시 커맨드 `/persona` 로 채널·페르소나·provider 별 모드를 바꾸면 세션이 재시작되며 잘린 프롬프트가 새로 주입된다.

추가 마커:

- `@레퍼런스` — 한 줄로 단독 등장하면 `추가 레퍼런스 폴더: <persona_dir 절대경로>` 로 치환된다. CLI 가 `--add-dir` 로 그 폴더를 읽을 수 있다.
- `@주인공` — 채널의 protagonist(처음 말을 건 사용자)의 Discord 멘션으로 치환된다. `@@1` 섹션 끝에 `주인공 = <@id>` 한 줄도 자동 삽입된다.

## 예시

`example/PROMPT.md` 를 보라. 복사해서 `dir` 이름을 바꾸면 바로 쓸 수 있다.
